AWS VPC & Networking

Thiết kế phân vùng Subnets

VPC  10.0.0.0/16
├── Public Subnet  10.0.1.0/24  (AZ-a)  → EC2 + Elastic IP
├── Private Subnet 10.0.10.0/24 (AZ-a)  → RDS PostgreSQL
└── Private Subnet 10.0.11.0/24 (AZ-b)  → Dự phòng Multi-AZ

Bảo mật định tuyến

  • Internet Gateway kết nối với Public Route Table để cấp Internet cho EC2.
  • RDS nằm trong Private Subnet hoàn toàn, không có public IP endpoint. Chỉ cho phép kết nối nội bộ từ EC2.

AWS IAM — Least Privilege

Nguyên tắc: Mỗi thực thể chỉ được cấp đúng những quyền tối thiểu cần thiết để vận hành:

Thực thể (Identity) Quyền được cấp (Permissions)
EC2 IAM Role SSM Session Manager + Secrets Manager (Read) + S3 (Read/Write)
S3 Client (IAM User) Chỉ PutObject + DeleteObject từ backend container
CloudFront Chỉ GetObject từ private S3 (thông qua OAC)

🔒 Tuyệt đối không sử dụng Root Account trong vận hành. Tránh hardcode credentials bằng cách gắn trực tiếp IAM Instance Profile vào EC2.

CI/CD Philosophy: Branch Protection

Nguyên tắc cốt lõi

Không có bất kỳ dòng code nào được đẩy trực tiếp vào nhánh main mà chưa được hệ thống tự động kiểm tra.

Cơ chế rào cản (Gatekeeping)

Chỉ khi tất cả các kiểm tra của GitHub Actions CI vượt qua thành công (Format, Lints, Unit Tests, Build), nút Merge Pull Request mới được mở khóa.

Feature Branch
▼
Pull Request (to main)
⬜ Run Code Format check
⬜ Run Unit Tests check
⬜ Verify application Build
▼
Merge approved & CD Triggered 🚀

Backend CI: Build & Push Image

Đóng gói & Phân phối

- name: Log in to GHCR
  uses: docker/login-action@v3
  with:
    registry: ghcr.io
    password: ${{ secrets.GITHUB_TOKEN }}

- name: Build and push
  uses: docker/build-push-action@v5
  with:
    push: true
    tags: |
      ghcr.io/uit-buddy/backend:${{ github.sha }}
      ghcr.io/uit-buddy/backend:latest

Cơ chế Gắn Tags

Mỗi lượt build thành công được gắn 2 tags:

  • {commit-SHA}: Cố định cho đợt build cụ thể (phục vụ rollback khi có lỗi).
  • latest: Luôn trỏ về phiên bản mới nhất vừa release.

Giúp thực thi các câu lệnh deploy trực tiếp trên môi trường EC2 mà không cần phải mở cổng SSH hay tạo thêm các phương thức kết nối trung gian kém bảo mật.

#!/bin/bash

Chỉ kích hoạt khi đẩy/merge code vào nhánh main:

Setup Flutter ➔ pub get
➔ Inject google-services.json & .env (từ GitHub Secrets)
➔ Giải mã Keystore từ Base64 để ký app (signing keys)
➔ flutter build apk --release --build-name=v1.0.${RUN_NUMBER}
➔ Upload file APK lên Firebase App Distribution (nhóm: tester)

Cơ chế đặt Version APK: v1.0.42-2026-05-25 (Mã build của GHA + thời gian build).
