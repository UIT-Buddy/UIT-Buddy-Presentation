Freezed & Code Generation

Freezed 3.1.0

• Đảm bảo tính bất biến (Immutability) của dữ liệu.
• Tự sinh code so sánh bằng `==` và băm `hashCode` cho các Models.
• Sinh hàm Json Serialization (fromJson/toJson) mượt mà.

@freezed
class Post with _$Post {
  const factory Post({
    required String id,
    required String content,
    required User author,
  }) = _Post;

  factory Post.fromJson(Map<String, dynamic> json) => 
      _$PostFromJson(json);
}
